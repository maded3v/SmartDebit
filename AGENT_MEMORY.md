# Agent Working Memory

## User Collaboration Preferences

- In build mode: start coding immediately after a very short plan.
- Do not stay in planning mode for long.
- Preferred flow: short plan -> code edits -> build/lint checks -> concise result.
- Avoid long abstract explanations before touching files.

## Response Style

- Keep messages concise and practical.
- Show concrete progress early.
- Ask questions only when truly blocked.
